Skill: dependency-flow-scan

Diagnose a codebase’s import-graph edges — cycles (strongly connected components), inversions (edges from stable modules to volatile ones, convicted only with git-churn corroboration), and skips (edges bypassing a layer the project itself declares) — and rank edge-repair candidates with a named-but-not-designed repair move (break / merge / re-point / promote). Emits a markdown + Mermaid report to the OS temp dir and stops at the design boundary, handing interface design to /grill.

The edge counterpart to skill-deepen-architecture: that skill judges the nodes of the module graph (is there enough behaviour behind each interface?); this judges the edges (do the arrows point the right way?). Together they cover most of what “architecture review” means for static structure.

When to use

  • Circular-dependency build errors, or “everything imports everything” complaints
  • Enforcing or auditing a layering (UI → service → storage) before or after a refactor
  • A change in one module keeps rippling into rebuilds or breakages across the graph
  • The user names “dependency direction”, “import cycles”, “layer violations”, or “module boundaries”

Skip when:

  • The question is module depth, not edge direction — /deepen-architecture
  • You want to know where change and cost actually concentrate — /churn-hotspot-scan
  • Behaviour recurs over time via runtime feedback loops — /structural-trace
  • You want a correctness review of a diff — /lean-review

Why it exists

Dependency rot is the edge-side failure /deepen-architecture can’t see: a codebase can be made of perfectly deep modules whose import arrows still form cycles, point from stable code into volatile code, or skip declared layers — and every change then ripples across the graph regardless of how good the individual modules are. Nothing in the catalog audited the import graph. Two design guards keep it honest: the metric alone never convicts (instability formulas must be corroborated by actual git churn), and the skip test refuses to run against a layering the project never declared — no invented architecture to convict against.
