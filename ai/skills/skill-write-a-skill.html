Skill: write-a-skill

Authors a new skill for .claude/skills/ from scratch to the vault’s house conventions, then stops at a draft routed to the auditors rather than self-grading. The generation front-half of the owned meta-trio — which was all audit/route (skill-quality-audit, skill-trigger-audit, which-skill) with no authoring scaffold.

When to use

  • The user wants to create, write, build, or scaffold a new skill or slash command for .claude/skills/
  • Drafting a SKILL.md and unsure of the required structure, frontmatter, or house conventions
  • Turning a procedure repeated by hand into a reusable skill
  • Deciding the contract (kind, output format, degrees of freedom) for a skill not yet written

Skip when:

  • Auditing or fixing an existing skill — that is /skill-quality-audit (body/contract) or /skill-trigger-audit (description/firing)
  • Routing a request to an existing skill — /which-skill
  • A one-off task an existing skill already covers (run /which-skill first if unsure)

Why it exists

The owned skill-authoring loop had only the back half: instruments that grade a finished SKILL.md. Nothing generated one. The result was that new skills got drafted ad hoc — from training-data defaults that reproduce the generic Anthropic skill shape but skip this vault’s house conventions: the catalog reference note, the _index.md entry, the verbatim-copy sync, the Counters <X> closing clause, the 1024-char-in-both-units cap whose tail (the distinctness clause) is what truncates first.

The design constraint, set in adoption-plan (T3.1), is that generation hands off to the existing, more rigorous auditors rather than duplicating their checks — the auditors run decoupled from the drafting context, so a same-context self-review would repeat the drafting blind spots. So the skill authors to skill-quality-criteria and then emits handoffs to /skill-quality-audit, /skill-trigger-audit, and /which-skill (the last as a catalog-collision test) instead of inlining a verdict. Its output contract is a definition-of-done (generative), not a Sound/Tune verdict.

Built 2026-06-08 as the cleanest single addition from the Matt Pocock skills adoption pass (source: the public write-a-skill skill in mattpocock/skills); the steal is the requirements → draft → review scaffold, not its lighter checklist, since the owned auditors already exceed it on rigor.
