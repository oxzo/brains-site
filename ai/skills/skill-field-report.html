Skill: field-report

Capture a one-line structured field report about a vault-built skill’s notable real-world behavior — caught something real, misfired, chafed, created value, or sparked an idea — and append it to journal/skill-field-log.md, degrading gracefully to a local file plus an emitted line when invoked outside the vault.

When to use

  • A vault-built skill just did something notable in any repo — a real catch, a misfire, friction at the deploy target, a concrete win, an improvement idea
  • A quick “anything notable?” pass at the end of an external-repo session where vault skills ran
  • Backfilling a remembered field event

Skip when:

  • Wrapping a whole session (files, claims, decisions) — commitment-ledger
  • The lesson needs paragraphs — retrospective
  • Recording a prediction — calibration-loop record

Why it exists

The vault is the lab; skills run and earn their value in external repos — and until this skill existed, none of that field evidence flowed back. Trigger audits simulated queries instead of replaying real ones, and there was no usage data to weigh skills for iteration or retirement. /field-report is the capture half of the field→lab feedback loop (development plan, Phase 1); the Phase-2 field review is the consumption half. The design constraint is habit survival: capture must cost under 30 seconds, so the skill is zero-interrogation — one line in, done, unknown context degrades to ? rather than blocking.

Phase-0 dogfood status

Conditional pass (2026-06-09). The structural gate holds — a filed line feeds a named consumer (the Phase-2 review) and so changes a future action by construction — but the log ships empty: no real field event was recoverable at build time specific enough to file without fabricating details, and padding the log at birth would violate its own notability gate. The gate completes when the first real entry lands from an external session. If the log is still empty at the Phase-2 review, that is the index-theater verdict on this skill and it should be retired by its own standard.
