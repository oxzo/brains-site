Skill: contradiction-scan

Scan a cluster of notes — a seed note’s link/tag neighborhood, a topic folder, or a tag — for pairs that silently disagree about the same fact, number, or claim. The skill assembles the note-neighborhood, extracts load-bearing empirical claims across the set, matches same-proposition pairs, and classifies each as agreement / tension / direct-contradiction / stale-superseded. It emits a conflict ledger — both note paths, both claims quoted, the reconciling regime (if any), and a resolution prompt — and stops. It reports; it never rewrites. The only skill in the catalog that ingests more than one note and reasons over the pair.

When to use

  • Auditing an aging, high-traffic topic cluster (folder or tag) for internal consistency
  • Integrating a new or substantially-edited note into a dense cluster — does it contradict what’s already there?
  • Before treating a belief that recurs across several notes as settled enough to build a decision on
  • Periodic corpus-maintenance, paired with /staleness-decay-scan (this catches disagreement; that catches expiry)

Skip when:

  • The input is one artifact (use /red-team, /reviewers-map, /bias-scan-human, /falsifiability-scan)
  • Claim-type triage on one note (use /claim-function-scan)
  • The artifact is a task queue (use /whittle-scan)
  • The assembled neighborhood has fewer than 2 notes, or no two share an overlapping empirical claim (refuse-to-scan)

Why it exists

Distributed inconsistency is the failure mode the scan counters — the memory-layer-specific decay where two notes written months apart each assert something about the same proposition, they disagree, and because you only ever read one note at a time the conflict is invisible. The vault asserts both X and not-X, a retriever surfaces whichever ranks higher, and the contradiction is trusted precisely because it lives in the persistent memory layer. No single-note skill can reach this: the unit of analysis is the note-pair across a retrieved set, and assembling that set is the mechanical work the skill automates. Three disciplines keep it from generating noise — report-don’t-rewrite (a ledger, never an edit, so one wrong inference can’t propagate corpus-wide), empirical-only (only truth-dependent claims can contradict; framing differences and deliberately-held alternatives don’t), and name-the-regime (two claims true in different contexts aren’t in conflict — a forced contradiction is the corpus analogue of a fabricated finding). See knowledge-base-entropy for the backing concept.
