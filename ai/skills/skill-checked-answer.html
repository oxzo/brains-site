Skill: checked-answer

Answers a question in a field the user doesn’t know and has three independent agents check the answer before the user relies on it: a re-deriver that works the question out without ever seeing the draft, a source checker that returns a quoted source per factual claim, and a cross-examiner that probes the draft for breaks. The user answers questions about their own situation and nothing else. The output is the reconciled answer, what checking changed, and what is still open.

Status: audited, not yet run. Drafted 2026-11-11 from a design conversation. /skill-quality-audit and /skill-trigger-audit both returned Tune on 2026-11-11 and their fixes were applied the same day without a re-audit; the /which-skill routing test was clean on four requests. It has no eval and no live run yet.

When to use

  • The user is about to act on an answer in a field they don’t know — medical, legal, financial, an unfamiliar technical area
  • “I can’t judge this myself”, “make sure this holds up”, “check this before I rely on it”, “have another agent check that answer”, “get a second opinion”
  • An answer just given is going into a decision and the user has no way to spot an error in it

Skip for a same-context self-check with the user as judge (/metacog-check), a single inversion (/disagree), a vague request that needs scoping (/clarify-first), a claim map of a written artifact (/reviewers-map), or any question too small to be worth three to five agent runs.

Why it exists

The self-check skills end in a gate where the user decides whether to trust the model’s report. skill-metacog-check says so directly: the AI reports, the principal decides. That gate does nothing when the user doesn’t know the field, because a fluent wrong answer and a fluent right one look the same to them. This skill counters unverifiable fluency by moving the judgment to checkers that each differ from the drafting context in what they have:

  • the re-deriver has not seen the answer, so it cannot simply confirm it;
  • the source checker has outside information, and must return the quote;
  • the cross-examiner has a brief to break the answer, not to answer the question.

Two design assumptions are untested here: that a re-deriver kept blind disagrees usefully more often than a reviewer shown the draft, and that the five probes (mechanism, boundary, counterexample, consequence, consistency) find breaks a plain “review this” would miss. The known limit is stated in the skill itself: agents on the same model share blind spots, so agreement between them counts as stability, never as verification.

The lightweight counterpart is the trial rule .claude/rules/question-shapes.md, which applies question-shape and field patterns inside ordinary answers at no extra cost and does not check facts.

Related
