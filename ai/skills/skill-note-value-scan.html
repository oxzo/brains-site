Skill: note-value-scan

Value the notes in a corpus so that something can finally leave it. The skill places each note in the irreplaceability × activation quadrant — could a frontier model regenerate this content today, and does anything actually use it — then checks whether the body still serves its stated intent:, flags redundant near-neighbours, and emits a ranked action table: keep / invest / merge / demote-to-snippet / re-verify / archive. It reports the actions; it does not perform them. In this vault the deterministic narrowing pass is tools/note_value.py; outside it, the same narrowing is done by hand.

When to use

  • A deliberate corpus-strategy review — the “what should leave?” pass, especially where nothing has ever been archived
  • A folder that has grown lopsided, bloated, or full of near-duplicates
  • Before a restructure, to decide what merges and what splits
  • The inverse question — which notes deserve deepening, splitting, or promotion to a hub
  • Paired with /staleness-decay-scan on a maintenance day — that one catches expiry, this one catches irrelevance

Skip when:

  • The target is a single artifact you want critiqued (use /red-team or /reviewers-map)
  • The scope is a queue, backlog, or commitment ledger (use /whittle-scan)
  • The problem is a perishable fact in one note (use /staleness-decay-scan)
  • The corpus is under ~30 notes — the thresholds are corpus-relative and meaningless on a handful (refuse-to-scan)

Why it exists

The vault is append-mostly, and git confirms it: zero note deletions and zero renames in knowledge/ across the entire history. knowledge-base-entropy named the stock-and-flow problem — capture is the inflow, and there is no outflow — and built two scans for decay inside notes. Neither decides which notes should leave. That gate is what this skill closes, and it is decay mode 5, commodity drift: the frontier moves, yesterday’s synthesis becomes today’s zero-shot answer, and a note’s value erodes without the note changing at all. No per-note read can catch that, because nothing about the note looks wrong.

Three design moves carry the weight:

  • Quadrant, not ranking. Irreplaceability and activation are orthogonal, and the off-diagonal cells hold the decisions: irreplaceable-but-unused work nobody links to (surface it, never bin it), and heavily-linked commodity content (an anchor, or a hub by habit?). A single score collapses both.
  • Being mentioned is not being used. In a densely cross-linked vault the median note already carries 9 editorial inbound links, so “is linked” separates nothing. Activation counts active channels — depended on by tooling, deliberately revisited, harvested for snippets, hub-scale linkage. Ordinary linkage is treated asymmetrically: it vetoes an archive verdict, but never counts as use.
  • The proxy shortlists; the read decides. Marker density can rank candidates, but assigning the irreplaceability band requires reading the note. A hub note can be pure commodity content and score low on every marker while being load-bearing.

The known limitation is stated in the skill body rather than designed away: the regeneration test is a model judging what a model could produce, so every verdict must quote its evidence and a human overrules per note.
