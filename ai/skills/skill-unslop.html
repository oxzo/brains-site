Skill: unslop

Rewrites a prose artifact to strip AI-writing tells and put voice back in, working from a fixed 31-pattern catalog: puffery, AI vocabulary, “not just X but Y”, em-dash and boldface overuse, inline-header lists, chatbot phrases, stacked hedging, filler, abstract metaphor nouns, passive voice, generic conclusions. It edits in place and logs every change before→after.

House-native port of cursor/plugins, pstack/skills/unslop, fetched 2026-08-19. The 31-pattern catalog is reproduced substantially verbatim — it is the substance of the skill. Four house changes:

  • A preservation floor (Step 0). Upstream has none, and two of its patterns are a fabrication trapdoor: pattern 5 says “name the source or delete” and pattern 21 says “find sources or remove”. Under house rules both resolve to delete or flag, never to supply a source you do not have. Facts, numbers, hedge strength, citations, quotes, and wiki-link targets survive verbatim, matching skill-prose-surgery’s floor.
  • A change log and a reachable clean verdict. Upstream rewrites silently. The port emits before→after per change, a needs-verification list for spans a fix would require knowing something to close, and a Clean verdict that leaves the file untouched — so “found nothing” is a successful run rather than a prompt to manufacture edits.
  • A register gate on patterns 27–31 (added 2026-08-19). The plain-speech block — “shorten dense sentences”, “active voice”, “cut adverbs”, “prefer the plain word” — is general prose-quality advice, not AI-tell detection, and fires on competent human writing. It now fires only in a paragraph where a register pattern (1–26) already fired; elsewhere the symptom is routed to /prose-surgery, /density-scan or /readability-scan and the span is left alone. Evidence: the head-to-head run logged 11 changes on the lowest-tell note in an eight-note sample, 5 of them from 27–31 alone — making the Clean verdict unreachable in practice, the exact axis-5 failure /skill-quality-audit passed the skill on because the contract defined one.
  • House calibration on three patterns. Em dashes (13), inline-header lists (16), and abstract metaphor nouns (26) collide with this vault’s established register. See below.

Upstream’s description read “Cut AI tells from any writing. Must always apply.” That was replaced. An always-fires rewrite skill is a standing hazard to every note in the vault, and the house description formula wants triggers plus a distinctness clause, not a mandate.

When to use

  • A draft reads like an LLM wrote it: “make this sound human”, “this is slop”, “de-AI this”, “strip the AI tells”, “less ChatGPT”
  • Before committing an AI-drafted note, README, or PR description that a human will read as authored
  • On external-facing prose (publish-tagged notes, external repo docs) where register is part of the deliverable
  • After skill-bias-scan-ai — that scan clears the epistemic layer, this one clears the register layer, and both can fire on the same artifact

Skip when:

  • The symptom is a hallucinated specific or unearned narrative — skill-bias-scan-ai, different layer
  • The reader has to re-parse sentences (referents, dependency distance, given-new) — skill-prose-surgery
  • You want a diagnosis without an edit — skill-readability-scan or skill-density-scan
  • The target is a journal entry, an inbox capture, or code

The three house calibrations

The reason this port needed adapting rather than dropping in:

PatternUpstream ruleHouse resolution
13, em dashesAvoid entirelyTwo modes. Vault-internal: fire on overuse only (>1 per paragraph, or two in one sentence) — em dashes are this vault’s standing device and voice is protected. External: apply as written, and external means leaving the vault’s voice (external repo, PR description, someone else’s publication) — not a publish tag, which ~216 notes carry as the site-visibility flag. Declare the mode before editing.
16, inline-header listsConvert bold-label-colon lines to proseUpstream already exempts the bold-lead-in-with-new-detail form, which is the form the vault uses throughout. Fire only on the restating kind.
26, abstract metaphor nounsReplace with the concrete wordSeveral listed words are canonical vault terms: “surface” (in skill-api-surface-scan), “harness”, “primitive”, “vector”, “scaffolding”. A word naming an established concept is vocabulary, not slop — replacing it manufactures exactly the drift skill-concept-drift-scan exists to catch. Fire only where no established term is invoked.

Why it exists

Every existing prose skill in the catalog either diagnoses without editing (skill-density-scan, skill-readability-scan) or edits a different axis (skill-prose-surgery, which owns parse load under hard meaning preservation). None of them own register — the vocabulary, punctuation, formatting habits, and absent point of view that make a passage read as machine-written even after it survives every correctness check. An AI-drafted note can be factually clean, well-cited, structurally sound, calibrated, and still unmistakably AI. That gap is what this skill closes.

The second half of the skill matters as much as the first. Upstream is explicit that removing patterns is half the job and voiceless prose is just as obvious a tell. The house limit on that: voice gets sharpened, not supplied. On someone else’s note, an inserted opinion is a fabricated claim, which puts it back under the vault’s authoring rules rather than its style rules.
